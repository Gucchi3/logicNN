# logicNNライブラリ

この章では、論理ゲートニューラルネットワーク（論理ゲートNN、LGN）を初めて学ぶ方に向けて、計算の仕組みとライブラリの使い方を説明します。Pythonの変数・関数・クラスを読めることを前提とし、論理回路やPyTorch固有の用語は本文で説明します。

「ANDやORのような0／1の演算を、どのように学習するのか」「ゲートの重みは何を意味するのか」「学習結果をどのようにCやVerilogへ変換するのか」を、数値例と実装の対応から確認していきます。

## 名前と範囲

| 名前 | このプロジェクトでの意味 |
|---|---|
| 論理ゲートNN | 論理ゲートを組み合わせて予測するモデルの総称 |
| `logicNN` | 学習・評価・保存などをまとめたアプリケーション。プロジェクトルートは `logicNN/` |
| `logicNN_core` | `utils/logicNN_core/` に同梱している汎用ライブラリ |
| `logicnn_core` | Pythonの `import` に指定するパッケージ名 |
| `torchlogix` | このライブラリの再構成元。利用者が別途cloneして読み込む構成ではない |

この章の「logicNNライブラリ」は `logicNN_core` を指します。ライブラリはMNISTに限定されず、入力形状・層構成・出力の集約方法をPythonで指定できます。一方、通常の `main.py` に新しいデータセットやモデルを追加するには、[アプリ側への登録](../extension.md)も必要です。

## 説明と実装を区別する

一般的な考え方を説明する数値例と、現在の実装で実行できるコード例を区別して掲載しています。論文で提案された手法がすべて実装されているわけではありません。

例えば、現在のライブラリはraw・warp・lightの各方式を持ちますが、対応する入力本数は方式ごとに異なります。また、Verilog出力は加算前の論理ビットまでであり、クラス判定やパイプラインレジスタは生成しません。

各関数の全引数・内部処理図・実ソースが必要な場合は、本文中の[コードリファレンス](/code-reference/utils/logicNN_core/src/logicnn_core/__init__)へのリンクを使用してください。この章は仕組みと使い方を理解するための説明であり、コードリファレンスの関数一覧を置き換えるものではありません。

## 実行前の準備

[環境構築](../../startup/setup.md)に従ってuvで仮想環境を作成し、同梱ライブラリをインストールして、その環境を有効化します。コード例は通常の `python` コマンドで実行します。

最初の基礎例とライブラリの直接利用例には、データセットのダウンロードやGPUは不要です。出力ファイルを作る例には保存先を明記しています。
