# 関連論文と読む順番

このページでは、論理ゲートNNの理解に役立つ7本の論文を紹介します。初めからすべてを読む必要はありません。まず本ガイドの説明と小さな実行例を理解し、関心のある疑問に対応する論文へ進んでください。

掲載年はarXivへの初回投稿年です。会議の開催年と異なる場合があります。書誌情報と論文の内容は2026年9月13日に確認しています。網羅的な最新論文一覧ではなく、本ライブラリを理解するための選定です。

## 1. 読む順番

| 順番 | 論文の略称 | 答えたい疑問 | 前提知識の目安 |
|---|---|---|---|
| 1 | Deep DLGN | ANDやORを、なぜ勾配降下法で学習できるのか | 真理値表、softmax、逆伝播 |
| 2 | Light DLGN | なぜ2入力ゲートを4個のパラメータで表せるのか | 真理値表、偏微分 |
| 3 | WARP | Walsh係数で何を学習し、多入力ゲートをどう扱うのか | 基底、行列、sigmoid |
| 4 | Convolutional DLGN | 画像の局所的な特徴を論理ゲートでどう処理するのか | 畳み込み、プーリング |
| 5 | Mind the Gap | 学習時と離散化後の精度差をどう小さくするのか | Gumbelノイズ、straight-through estimator |
| 6 | DWN | LUTそのものを学習する別の方法はあるのか | LUT、近似的な微分 |
| 7 | Recurrent DDLGN | 時系列や文章にも論理ゲートNNを使えるのか | 再帰型NN、隠れ状態 |

難易度は本ガイドの読者を想定した目安です。1〜3は現在の `raw`・`light`・`warp` の違いを整理するため、4以降は目的に応じて読む構成にしています。

## 2. 基礎となる論文

### 2.1 Deep Differentiable Logic Gate Networks

Felix Petersenほか、2022年。[arXiv:2210.08277](https://arxiv.org/abs/2210.08277)

**学べること:** 離散的な論理ゲートを、微分可能な計算へ置き換える基本的な考え方です。学習中は複数の論理演算を連続的な重みで組み合わせ、推論用には1個の演算へ確定します。[原論文](https://arxiv.org/abs/2210.08277)

**本ライブラリとの関係:** `raw` は、2入力に対する16種類の論理演算から学習する方式です。まず [Rawの実装](../../code-reference/utils/logicNN_core/src/logicnn_core/parametrizations/raw.md)と照合し、`forward()` で用いる学習時の値と、`truth_tables()` で得る離散的な表を区別してください。論文中のモデル構成・学習条件・速度が、そのまま現在のモデルに適用されるわけではありません。

**読み方:** 最初は導入と1個のゲートの学習式を読み、ANDの連続式が `a * b` になることと、演算を選ぶためのパラメータの意味を確認します。実験結果や高速化の詳細は後から読んでも構いません。

### 2.2 Light Differentiable Logic Gate Networks

Lukas Rüttgersほか、2025年。[arXiv:2510.03250](https://arxiv.org/abs/2510.03250)

**学べること:** 16個の演算候補を組み合わせる代わりに、真理値表の各行に対応する値を学習する表現です。2入力なら4行なので4個のパラメータで表せます。原論文では、この表現変更と初期化が勾配や離散化へ与える影響を調べています。[原論文・第3節](https://arxiv.org/html/2510.03250v1#S3)

**本ライブラリとの関係:** [Lightの実装](../../code-reference/utils/logicNN_core/src/logicnn_core/parametrizations/light.md)の、入力に応じた基底と真理値表の係数を組み合わせる計算に対応する考え方です。ただし、論文の実験では正弦関数型の推定関数も用いており、現在の実装はsigmoid系のsamplingを使います。論文の実験実装をそのまま再現したものではありません。[原論文・第4.2節](https://arxiv.org/html/2510.03250v1#S4.SS2)

**読み方:** 第3.2節を中心に、入力が `00`・`01`・`10`・`11` のとき、対応する係数だけが出力へ現れることを確認します。次に、入力が連続値の場合には複数の項を足し合わせる計算になることを追ってください。

### 2.3 WARP Logic Neural Networks

Lino Gerlachほか、2026年。[arXiv:2602.03527](https://arxiv.org/abs/2602.03527)

**学べること:** WARPは *WAlsh Relaxation for Probabilistic* の略です。論理関数をWalsh基底の係数で表し、学習時の連続計算と推論時のLUTをつなぎます。多入力LUTに加え、確率的な学習、残差初期化、学習可能な二値化閾値も扱います。[原論文](https://arxiv.org/abs/2602.03527)

**本ライブラリとの関係:** [Warpの実装](../../code-reference/utils/logicNN_core/src/logicnn_core/parametrizations/warp.md)を理解するための中心的な文献です。現在の `warp` は1・2・4・6入力に対応します。ただし、Pythonコードの符号規約・真理値表の順序・境界の判定は、現在の実装を基準にしてください。別機能である `warp` 正則化は実装保留であり、方式名が同じだから使用できるとは限りません。

**読み方:** 第3節で他方式との差を確認し、第4.1節の2入力の例から第4.2節へ進みます。まず「基底は計算の部品、係数はその組合せを決める学習対象」と理解し、一般的な証明は後回しにして構いません。

## 3. 目的に応じて読む論文

### 3.1 Convolutional Differentiable Logic Gate Networks

Felix Petersenほか、2024年。[arXiv:2411.04732](https://arxiv.org/abs/2411.04732)

**学べること:** 論理ゲートの木を画像の各位置へ適用する畳み込み、OR pooling、学習を安定させる残差初期化です。全入力を平坦化して処理する構成から、近隣の画素に同じ演算を適用する構成へ進むための文献です。[原論文](https://arxiv.org/abs/2411.04732)

**本ライブラリとの関係:** `LogicConv2d`・`LogicConv3d`・`OrPooling2d`・`OrPooling3d` と、`weight_init="residual"` を理解する背景になります。3D対応などを含む現在のAPI全体を、この論文が提案・検証したという意味ではありません。[畳み込みの実装](../../code-reference/utils/logicNN_core/src/logicnn_core/layers/convolution.md)と[プーリングの実装](../../code-reference/utils/logicNN_core/src/logicnn_core/layers/pooling.md)を対応付けて読んでください。

**読み方:** 通常のCNNと論理ゲート木の比較から始め、受容野・木の深さ・出力チャネルの意味を整理します。「残差初期化」は重みの初期状態を選ぶ方法であり、別経路を接続する残差ブロックそのものではない点も確認してください。

### 3.2 Mind the Gap: Removing the Discretization Gap in Differentiable Logic Gate Networks

Shakir Yousefiほか、2025年。[arXiv:2506.07500](https://arxiv.org/abs/2506.07500)

**学べること:** 連続的な演算の組合せで学習したモデルを、1個の論理演算へ確定すると挙動が変わる問題です。原論文では、Gumbelノイズとstraight-through estimatorを学習へ取り入れ、離散化前後の差を小さくする方法を扱います。[原論文](https://arxiv.org/abs/2506.07500)

**本ライブラリとの関係:** `sampling="soft"` と `sampling="gumbel_hard"` の違いを考える際の参考になります。[samplingの実装](../../code-reference/utils/logicNN_core/src/logicnn_core/functional/sampling.md)を読み、順伝播で使う値と逆伝播で使う近似を分けて確認してください。同じ名称の要素があっても、論文の手法・実験全体を再現したことにはなりません。

**読み方:** まず離散化前後の評価を比較する図を読みます。学習時の精度だけでモデルを判断せず、離散化したモデルも評価する必要がある理由をつかんでから、ノイズと勾配の議論へ進みます。

### 3.3 Differentiable Weightless Neural Networks

Alan T. L. Bacellarほか、2024年。[arXiv:2410.11112](https://arxiv.org/abs/2410.11112)

**学べること:** LUTを接続したネットワークを、二値値に対する近似的な微分で学習する別系統の方法です。原論文では、接続の学習、出力の集約方法の学習、スペクトルに基づく正則化も提案しています。[原論文](https://arxiv.org/abs/2410.11112)

**本ライブラリとの関係:** `light` や `warp` の別名ではありません。現行ライブラリには `kind="dwn"` はなく、この論文のExtended Finite Difference、Learnable Reduction、Spectral Regularizationを一式実装しているわけでもありません。「LUTを使う」という共通点と、「何をパラメータにし、どう勾配を計算するか」という違いを理解するための比較文献です。

**読み方:** 最初のモデル全体図を見て、二値化・LUT・接続・出力集約のどこを学習するかを整理します。次に、LUTの参照先を少し変えたときの出力差を、勾配の近似に使う考え方を読んでください。

### 3.4 Recurrent Deep Differentiable Logic Gate Networks

Simon Bührerほか、2025年。[arXiv:2508.06097](https://arxiv.org/abs/2508.06097)

**学べること:** 前の時刻の状態を次の計算へ引き継ぐ再帰構造へ、論理ゲートNNを拡張する研究です。画像分類だけでなく、入力列から出力列を生成する課題を扱っています。[原論文](https://arxiv.org/abs/2508.06097)

**本ライブラリとの関係:** 発展研究としての紹介です。現在は専用の再帰層や、状態を保持する順序回路の自動生成は提供していません。生成Verilogにクロックやレジスタが自動で追加されることもありません。

**読み方:** 再帰型NNに不慣れな場合は、先に「隠れ状態」と「時刻方向に同じ処理を繰り返す」という考え方を学びます。そのうえで、論理ゲートが現在の入力と過去の状態をどう組み合わせるかを確認してください。

## 4. 論文からコードへ戻るときの確認事項

論文の説明は学習の背景、コードリファレンスは現在の実装を確認するために使い分けます。論文の式や実験設定を取り入れるときは、次の順で確認してください。

1. **変数の意味:** 論文の「重み」が、ゲート選択のlogit・真理値表の係数・Walsh係数・接続選択のどれを指すかを確認する。
2. **値と順序:** 入力が `0/1` か `-1/+1` か、真理値表の行と係数がどの順序かを確認する。
3. **学習と評価:** sigmoid・softmax・乱数・閾値判定が、どのモードで使われるかを確認する。
4. **実装範囲:** 対応する入力本数、接続方式、層、回路出力の範囲を確認する。論文の全機能が利用できるとは考えない。
5. **小さな例での確認:** [ライブラリの直接利用](../core-library.md)のような小規模モデルで、出力shape、逆伝播、評価、回路化を順に確認する。

本ライブラリはtorchlogixを参考に再設計したものであり、torchlogixを実行時に呼び出すラッパーではありません。torchlogix自体はdifflogicを基礎とするライブラリで、その関係は[torchlogixのREADME](https://github.com/ligerlac/torchlogix)にも記載されています。本プロジェクトで参照した実装と変更内容は、同梱の `utils/logicNN_core/THIRD_PARTY_NOTICES.md` に記録されています。

論文に掲載された精度・速度・回路規模は、それぞれのモデル、データ、ハードウェア、学習条件に依存します。本ライブラリで同じ方式を選択しただけで、その結果が再現されるとは限りません。
