# ユーザーガイド

このガイドは、環境構築と初回の学習を終えた利用者を対象に、目的別の操作方法を説明します。初めて使用する場合は、[スタートアップガイド](../startup/index.md)から進めてください。

各コマンドは、使用する仮想環境を有効化し、`main.py` があるプロジェクトルート `logicNN/` で実行します。

## 設定変更と実装追加の違い

既存のモデル・データセットに対する学習回数、学習率、バッチサイズ、保存先などはJSONで変更します。一方、モデル構造、新しいデータセット、未登録の損失関数などを使用するにはPythonの実装を追加します。

学習アプリに現在登録されている組み合わせは、MNISTと `mnist_lgn` です。汎用ライブラリ `logicNN_core` の利用範囲はMNISTに限定されませんが、アプリの共通学習処理はクラス分類を対象としています。

## 他の文書との使い分け

操作方法は本ガイド、関数ごとの引数・戻り値・処理図は[コードリファレンス](../code-reference/index.md)、システム全体の設計方針は[仕様書](../specifications/index.md)で説明します。本ガイドの設定例と操作手順は、現在の実装に対応しています。
