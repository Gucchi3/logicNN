# 受入の現在地

2026-09-13の検証状況。細かな単体テストの件数ではなく、実際の利用手順がどこまで確認できたかを示す。仕様と合格条件は [テスト仕様](./test-specification.md#102-受入ケース)、実行条件と証跡は [検証記録](./verification.md) を正本とする。

最終の通常回帰は **4,866件合格・53件skip**。これは以下の受入全体が完了したという意味ではない。とくにAT-009は別途実行で不合格となっている。

| ID | 利用手順 | 状態 |
|---|---|---|
| AT-001 | 実MNISTの新規学習・保存・最終test | CPUの1 epoch smoke合格 |
| AT-002 | bestの重みからepoch 1の新規学習 | 実CLI合格 |
| AT-003 | finalの重みからepoch 1の新規学習 | 実CLI合格 |
| AT-004 | bestから3形式生成、実C／Verilog比較 | 合格。実CLI生成済み3ファイルの同一性と実C／Verilogも追加照合 |
| AT-005 | 回路無効時は回路を生成しない | 実CLI合格 |
| AT-006 | 代表的異常を学習前に診断 | 5区分の実CLIテスト合格 |
| AT-007 | 旧版からの精度低下が1ポイント以内 | 正式な100 epoch比較は未実施 |
| AT-008 | 文書サイト・開発テストのない運用候補 | 文書を整備中。運用候補と最終移行は未完 |
| AT-009 | 同条件学習の重み・記録再現 | 厳密比較が不合格。決定性の仕様整合を局所保留 |
| AT-010 | 正常／異常時のRich表示 | 実CLIと出力テストで確認。最終的な見やすさは利用者の確認対象 |

「合格」は表の範囲に限る。1 epochの動作確認を100 epochの精度保証とせず、同じケースを追加実行した件数を別の受入条件の達成数へ加算しない。

## core側に残るもの

1. [Alkaidの数値契約](./logicnn-core/alkaid-decision.md)とadapter実装。
2. [参照モデルの未成立3系列](./logicnn-core/verification.md#c12部分実装-汎用の参照モデル)。元情報を保存し、別方式へ無断で置換していない。
3. Warp rank 1／4／6、Light rank 4／6の回路出力は段階実装のまま。通常学習への対応とは区別する。
4. CPUのTensor native peak memory。小型28条件の初回速度基準は実測済みだが、Pythonのtracemallocだけではnative peakを測定できない。
5. CUDA実機検証。現在のCPU環境では未実施とし、CPUの検証結果へ混ぜない。

## 最終移行

受入完了・利用者の判断後に運用候補から開発用テスト・専用依存・キャッシュを除外する。今の開発フォルダから先にテストを削除せず、旧 `logicnn_old/` も現時点では廃止していない。
