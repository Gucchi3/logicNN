# データセットのダウンロード

このページでは、手書き数字の画像データセットMNISTを例に、学習用データを取得します。データセットの取得は学習処理から分離されており、`python main.py` は未取得のデータを自動でダウンロードしません。

## 1. MNISTを取得する

[環境構築](./setup.md)で用意した仮想環境を有効にし、プロジェクトルートで実行します。

```shell
python tools/download_dataset.py --dataset mnist --root data
```

| 引数 | 指定内容 |
|---|---|
| `--dataset mnist` | 取得するデータセットの登録名 |
| `--root data` | データの保存先となる親フォルダ。相対パスはプロジェクトルートを基準に解釈する |

MNISTは `data/mnist/` の下に保存されます。内部の `MNIST/raw/` などのフォルダはtorchvisionが作成するため、手動で配置し直す必要はありません。取得済みの正常なデータがある場合は再利用します。

## 2. 取得結果を確認する

正常に終了すると、端末に「データセットの準備が完了しました」と表示されます。続けて、保存先と次の件数が表示されることを確認してください。

| 取得するデータ | 件数 |
|---|---:|
| 公式の学習用データ | 60,000 |
| 公式のテスト用データ | 10,000 |

ダウンロードに失敗した場合は、エラーに表示された保存先を確認し、ネットワーク接続、書き込み権限、空き容量を確認してください。

## 3. 学習時のデータの扱いを確認する

MNISTでは、学習を開始すると公式の学習用60,000件を学習用と検証用に分割します。ダウンロード時に別々のフォルダへ分割するわけではありません。

| 用途 | 件数 | 使用するタイミング |
|---|---:|---|
| 学習用 | 50,000 | 各epochの重み更新 |
| 検証用 | 10,000 | 各epoch終了時の評価とbestモデルの選択 |
| テスト用 | 10,000 | 全epoch終了後、bestモデルによる最終評価 |

分割には `run.seed` を使用します。画像の二値化も読み込み時に実行されるため、二値化済みの画像ファイルを別途作成する必要はありません。現在のMNIST処理では、正規化後の画素値が0より大きければ1、それ以外は0に変換します。

### 別のデータセットを使用する場合

本ガイドではMNISTを使用しますが、データの保存先や共通処理はMNIST専用ではありません。ただし、現在のデータ取得ツールに登録されているのはMNISTのみです。別のデータセットを使用するには、その取得処理・読み込み処理と対応するモデルを用意する必要があります。名前の変更だけでは切り替えられません。

保存先を `data` 以外に変更した場合は、次の手順で用意する学習設定の `data.root` にも同じ親フォルダを指定してください。例えば `--root datasets` の場合、保存先は `datasets/mnist/`、設定値は `"root": "datasets"` です。`data.root` に末尾の `mnist` を追加する必要はありません。
