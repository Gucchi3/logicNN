# logicNN

logicNNは、論理ゲートニューラルネットワークを学習・評価し、学習済みモデルから論理回路、CコードおよびVerilogコードを生成するためのソフトウェアです。

## 現在の文書

- [仕様書](./specifications/index.md): 要件、設計、処理フローおよび設計図
- [スタートアップガイド](./startup/index.md): 環境準備、データ取得、最初の学習
- [ユーザーガイド](./user-guide/index.md): 設定、重みの初期化、成果物、拡張、エラー対応
- [コードリファレンス](./code-reference/index.md): ソース階層から探す関数説明・内部アクティビティ図（main.pyを試作中）

操作方法から探すときはガイド、コードから利用するときはAPI、設計理由や保証範囲は仕様書を確認してください。現在は開発・検証中です。[実装・検証記録](./specifications/verification.md) に、実行済みの結果と残る確認を記載しています。
